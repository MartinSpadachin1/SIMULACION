# SIMULACION — Expreso Norte

Aplicación de simulación desarrollada en React y Vite.

## Ejecutar localmente

Desde `frontend`:

```bash
npm install
npm run dev
```

Abre el enlace que muestra Vite en tu navegador.

## Qué contiene

- `src/App.jsx`: lógica de simulación y presentación
- `src/App.css`: estilos de interfaz
- `src/index.css`: estilos globales

## Nota

Este proyecto funciona completamente en el frontend; no se utiliza backend.
